Projects carried out during training

NetworkCiscoPacket Tracer

Model of a VLAN-segmented network with inter-VLAN routing

Context
First-year BTS SIO SISR lab at IMIE, done in a simulator.
Need
Separate the traffic of several departments on one local network, while still letting them communicate in a controlled way.
Actions taken
Created VLANs on the switches, assigned access ports, configured an 802.1Q trunk link, set up inter-VLAN routing, addressed the hosts, tested connectivity (ping) between VLANs.
Technologies used
Cisco Packet Tracer, Cisco IOS (command line), 802.1Q VLANs, IPv4 addressing.
Results / Deliverables
Working model: each VLAN is isolated and traffic between VLANs goes through routing.
Skills used
  • B2.1.5 Model and prototype an infrastructure solution that meets the expected quality of service
  • B2.2.1 Install and configure infrastructure components
  • B2.2.5 Test the integration and acceptance of an infrastructure solution
